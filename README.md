# Gerador-de-Curr-culos
Projeto acadêmico desenvolvido utilizando Python e HTML, com o objetivo de criar um gerador de currículos de forma simples e prática. A aplicação permite inserir informações pessoais, acadêmicas e profissionais para gerar um currículo organizado e estruturado.
O projeto foi desenvolvido como parte do aprendizado em programação e desenvolvimento web.
